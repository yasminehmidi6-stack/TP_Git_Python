TP2 - README
1. Présentation
Dans ce TP, nous avons réalisé un programme Python appelé Mon assistant de révision.
Ce programme demande à l'utilisateur son prénom, la matière à réviser et le temps de révision.
Le fichier principal du programme est main.py.
2. Les versions du programme
V1 : Afficher un message de bienvenue.
V2 : Ajouter le prénom de l'utilisateur.
V3 : Ajouter la matière à réviser.
V4 : Ajouter la durée de révision en minutes.
3. Comment exécuter le programme ?
Pour exécuter le programme, il faut :
Ouvrir le dossier dans VS Code.
Ouvrir le fichier main.py.
Cliquer sur Run Python File.
Entrer le prénom.
Entrer la matière.
Entrer la durée de révision.
4. Les commandes Git utilisées
git init : créer un dépôt Git.
git add : ajouter les modifications.
git commit : enregistrer les modifications.
git push : envoyer le projet vers GitHub.
git pull : récupérer les modifications depuis GitHub.
